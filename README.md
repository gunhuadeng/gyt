# 估研台 · 住宅市场比较法测算工作台

本地运行的住宅房地产税务估价测算工具。它按《住宅测算表.xlsx》的规则计算三个可比实例，并回填用户选择的 Excel 原表。

## 启动

双击 `start.bat`，或在当前目录运行：

```powershell
python app.py
```

浏览器会自动打开 `http://127.0.0.1:8765`。按 `Ctrl+C` 停止服务。

## 使用流程

1. 录入报告编号、价值时点和估价对象信息。
2. 核对证载楼层、地下层数、地上总层数和所在楼层。
3. 展开“权益状况与区位状况资料”，填写权证、产权人、权利类型、使用期限、四至及区位描述。
4. 录入三个可比实例。
5. 填写区域因素等级。
6. 按需调整每个案例的 P1 交易情况系数、P2 市场状况系数及修正依据。
7. 核对页面中的比准价格、评估单价和评估总价。
8. 从顶部选择未填写的 Excel 原表。
9. 导出填写后的 XLSX 副本或正式 Word 报告。

## 楼层口径

本项目支持“证载楼层”和“修正楼层”分离。例如：

```text
证载楼层：18/19
地下层数：1
地上总层数：18
所在楼层：18
修正楼层：18/18（顶层）
层次系数：99.4%
```

层次修正只使用地上总层数和住宅所在楼层。

## 当前计算规则

- 三个案例必须完整填写。
- 区域因素按一等至五等换算标准得分，P4为估价对象与案例区域总分之比。
- 实体系数包括面积、结构、层次、成新、朝向和东西至。
- 高层层次系数按原工作簿公式计算。
- 装修扣减为案例和估价对象装修重置价差额。
- P1交易情况修正和P2市场状况修正默认 `1.000`，允许逐案例调整。
- 三个比准价格采用算术平均，不使用权重。
- 评估单价取整到元，评估总价按建筑面积计算后取整。

本次参考项目预期结果：

```text
比准价格：2,824 / 2,734 / 2,778 元/㎡
评估单价：2,779 元/㎡
评估总价：337,454 元
```

## Excel 导出

- 必须从页面顶部选择原始 `.xlsx`。
- 程序只修改 `1-1 测算表` 的输入单元格。
- 隐藏工作表、图片、合并单元格、批注、公式和样式不会被重新绘制。
- 导出文件会设置为打开时完整重算。
- 原始 Excel 不会被覆盖。

## Word 报告

系统已保存用户提供的正式报告模板 `templates/formal-report-template.docx`。导出时会保留原模板的章节、页眉页脚、字体、表格、声明和附件图片，并同步更新：

- 项目名称、报告编号、价值时点和坐落。
- 产权人、不动产权证号、权利类型、土地用途、使用期限等权益状况。
- 四至、区位状况描述和区位分析。
- P1/P2 修正系数及其说明。
- 三个案例的比准价格、评估单价、总价和人民币大写。
- 证载 18/19 层与地上 18/18 层顶层修正口径。

模板中的既有签名图片会原样保留；正式签发前必须由报告机构自行复核签署流程。

## 文件

- `app.py`：本地 Web 服务。
- `residential_rules.py`：区域、结构、朝向和楼层修正规则。
- `residential_calculator.py`：住宅市场比较法计算引擎。
- `xlsx_template.py`：原 Excel 输入单元格回填。
- `report_template.py`：正式 Word 模板填充。
- `office_export.py`：无模板时的备用 Word 草稿生成。
- `templates/`：已保存的正式报告模板。
- `static/`：浏览器界面。
- `tests/`：计算、模板和浏览器回归测试。

## 使用限制

软件生成的是测算和专业复核用报告。产权信息、案例来源、区域评分、修正系数和最终估价结论必须由具备相应资质的房地产估价专业人员复核确认。
